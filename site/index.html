배포 준비 중

소스 저장소는 Public으로 공개되어 인증 없이 Git으로 읽을 수 있습니다. 아직 검증된 운영 릴리스 태그가 없으므로 아래 설치 절차는 개발자용입니다. 깨끗한 Raspberry Pi 전체 설치와 실물 주행 검증은 남아 있습니다. 이 사이트는 로봇 조종 API를 제공하지 않습니다.

01 / REQUIREMENTS

설치 전에 확인하세요.

로봇

  • Raspberry Pi · Ubuntu 24.04 ARM64
  • ROS 2 Jazzy (없으면 기존 설치기가 준비)
  • NetworkManager · 일반 사용자와 sudo 권한
  • STS3215 바퀴 ID 7·8·9
  • 확인한 바퀴 순서·방향·치수의 YAML 프로필
  • 확인한 모터 USB와 본체 카메라 경로

PC

  • 검증한 개발 환경: Linux · Python 3.12 · OpenSSH · Git
  • 설치 도우미의 프로필 검사: PyYAML 6.0.3
  • Windows/macOS 도우미 실행은 아직 미검증
  • PC→Pi SSH 접속과 호스트 키 지문 확인
  • 공개 원본은 PC와 Pi에서 인증 없이 읽기 가능

팔 제어·자율주행·모델 학습은 포함하지 않습니다. 다른 OS·모터의 호환성을 가정하지 않습니다.

02 / NETWORK

Pi에도 인터넷이 필요합니다.

A. 공유기 Ethernet

인터넷 공유기와 Pi를 랜선으로 연결하고 DHCP 주소를 확인합니다. 최초 설치에 권장합니다.

B. 노트북 인터넷 공유

노트북 Wi-Fi → Ethernet 공유를 설정한 뒤 Pi를 연결합니다. 랜선 연결만으로 인터넷 공유가 켜지지 않습니다.

C. Pi Wi-Fi

기존 Wi-Fi로 설치할 수 있습니다. 이후 AP 전환은 SSH를 끊을 수 있으므로 자동으로 전환하지 않습니다.

OS별 인터넷 공유와 검사

Ubuntu: NetworkManager 유선 IPv4를 “다른 컴퓨터와 공유”. Windows: 인터넷 어댑터의 인터넷 연결 공유에서 Ethernet을 선택. macOS: 시스템 설정 → 일반 → 공유 → 인터넷 공유에서 Wi-Fi→Ethernet 선택. 메뉴·지원 여부는 OS 버전별로 다르며 Windows/macOS 실기기는 미검증입니다.

Pi의 실제 IP·기본 게이트웨이·DNS·GitHub HTTPS·Git 읽기·Ubuntu/ROS 패키지 접근을 확인하세요. 도우미는 네트워크 설정을 자동 변경하지 않습니다.

03 / GIT INSTALLATION

검증한 태그에서 설치합니다.

GitHub 소스 저장소 ↗ · 소스는 공개되어 있습니다. 관리자가 제공한 실제 릴리스 태그와 전체 커밋을 사용하세요. 아직 검증된 운영 릴리스는 없습니다.

  1. PC에서 Git으로 소스 준비
    git clone https://github.com/seungjin-02/xlerobot.git
cd xlerobot
python3 -m venv .venv-assistant
.venv-assistant/bin/python -m pip install PyYAML==6.0.3

    인증 정보는 Git 자격 증명 관리자를 사용하세요. URL에 토큰을 넣지 마세요. 다운로드 ZIP 설치 경로는 제공하지 않습니다.

  2. Pi의 SSH·Git 준비

    현장에서 SSH 호스트 키를 확인하고 일반 사용자로 접속합니다. Pi에 Git과 python3-yaml을 설치하고 공개 원본의 Git 읽기를 확인하세요. Private 배포 출처는 Pi 자체 인증이 별도로 필요합니다. 도우미는 PC의 토큰·개인키를 Pi로 복사하지 않습니다.

  3. PC에서 사전 검사
    .venv-assistant/bin/python tools/install_assistant.py \
  --host USER@PI_ADDRESS \
  --tag VERIFIED_TAG --commit VERIFIED_40_CHARACTER_COMMIT

    대문자 항목을 실제 값으로 바꾸세요. --install 없이는 사전 검사만 수행합니다.

  4. 확인한 프로필로 설치
    .venv-assistant/bin/python tools/install_assistant.py \
  --host USER@PI_ADDRESS \
  --tag VERIFIED_TAG --commit VERIFIED_40_CHARACTER_COMMIT \
  --install --profile /path/to/verified-profile.yaml \
  --serial-port /dev/serial/by-id/VERIFIED_MOTOR_USB \
  --camera /dev/v4l/by-path/VERIFIED_FRONT_CAMERA \
  --confirm-wheel-map --output lekiwi-installed.html

    Pi에서 Git clone→태그 커밋 대조→기존 install.sh→서비스·본체 JPEG 검사 순서로 진행합니다. SSH 터미널에서 sudo 인증과 새 PIN을 입력합니다. 기존 설치는 덮어쓰지 않습니다.

수동 업데이트와 복구 절차 ↗ · GitHub Releases ↗ · 검증 범위 ↗

현재 main을 실제 장비에 적용한 검증은 서비스·인증·두 카메라·설정 보존 범위입니다. 모터 활성화·주행·재부팅·새 OS 전체 설치까지 검증한 운영 릴리스는 아닙니다.

04 / LOCAL CONNECTION

이제 스마트폰으로.

  1. 설치 완료 안내 파일 lekiwi-installed.html을 PC 브라우저에서 엽니다.
  2. 최초 설치 후 Pi를 재부팅합니다. AP가 없으면 네트워크 안내를 확인하세요.
  3. 스마트폰 Wi-Fi 설정에서 안내된 AP에 연결합니다. AP 암호는 관리자에게 별도로 받습니다.
  4. 웹앱 URL QR을 스캔하거나 http://192.168.4.1:8090을 직접 입력합니다.
  5. PIN 인증 후 조종·기록·시스템 관리 화면을 사용합니다.

URL QR은 Wi-Fi에 연결하거나 PIN 인증을 대신하지 않습니다. Wi-Fi QR은 별도 비공개 연결 카드에서 선택적으로 확인합니다. PIN·인증 토큰은 QR에 넣지 않습니다. QR 생성 실패 시 수동 주소를 사용하세요.

05 / RELEASES

업데이트도 검증한 버전으로.

최신 main을 자동 설치하지 않습니다. 관리자가 릴리스 출처·태그·전체 커밋·실물 검증 결과를 확인한 뒤 SSH에서 수동 업데이트합니다. 현재 버전은 로컬 시스템 관리 화면에 표시됩니다.

조종·기록 종료 → 설정·서비스·기존 ROS 빌드·데이터 백업 → 변경 의존성 확인 → 태그 전환 → 설치기 재실행 → 서비스·카메라 확인 → 재부팅·현장 검증 순서입니다. 자세한 명령과 복구는 저장소의 docs/UPDATE.md를 확인하세요.

브라우저에서 업데이트를 실행하는 기능은 이번 버전에 없습니다.

HELP / FAQ

연결이 막혔나요?

GitHub를 읽을 수 없어요.

Pi에서 GitHub DNS·HTTPS 접근과 공개 저장소 Git 읽기를 확인하세요. Private 배포 출처라면 읽기 권한도 필요합니다. PC에서 clone된다고 Pi 인증도 준비된 것은 아닙니다. 관리자에게 권한을 요청하고 토큰을 채팅·로그·명령 인자에 넣지 마세요.

SSH가 끊겼거나 설치가 실패했어요.

자동으로 폴더를 지우거나 재설치하지 마세요. 남은 체크아웃과 설정을 보존하고 docs/TROUBLESHOOTING.md의 systemctl·journalctl 진단을 수행하세요. AP 전환은 기존 Wi-Fi SSH 연결을 끊을 수 있습니다.

조종 화면이 열리지 않아요.

실제로 로봇 AP에 연결했는지 확인하고 “인터넷 없이 연결 유지”를 선택하세요. QR이 없어도 수동 주소를 사용할 수 있습니다. 이 공개 안내 사이트에서 로봇을 조종할 수는 없습니다.

데모가 동작하면 실물도 검증된 건가요?

아닙니다. 깨끗한 Raspberry Pi에서 전체 설치, 재부팅/AP, 카메라 역할, 모터 방향·정지, 통신 장애와 주행 기록을 별도 검증해야 합니다. 연결 손실 시 기존 정책은 마지막 출력을 최대 10초 유지합니다. 소프트웨어 정지 요청은 물리적 정지를 보장하지 않습니다.
