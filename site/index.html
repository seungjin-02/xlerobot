현재 개발자용 설치 단계입니다.

검증된 설치 버전은 아직 준비 중입니다. 처음 설치할 때는 관리자에게 사용할 버전과 기기 설정 파일을 먼저 받으세요.

01 / 준비

PC와 로봇을 준비하세요.

로봇

Ubuntu 24.04 ARM64가 설치된 Raspberry Pi와 LeKiwi 베이스가 필요합니다.

PC와 랜선

설치 도우미는 Linux PC 기준입니다. 로봇을 인터넷 공유기나 인터넷 공유를 켠 노트북에 랜선으로 연결하세요.

관리자에게 받을 것

로봇의 IP·SSH 계정, 설치 버전, 해당 로봇의 설정 파일과 모터·카메라 연결 경로를 준비하세요.

설치할 때는 PC와 로봇 모두 인터넷이 필요합니다. 설치 후 조종과 기록은 인터넷 없이 사용할 수 있습니다.

02 / 설치

처음 설치할 때만 진행하세요.

  1. PC에서 설치 도우미 준비
    git clone https://github.com/seungjin-02/xlerobot.git
cd xlerobot
python3 -m venv .venv-assistant
.venv-assistant/bin/python -m pip install PyYAML==6.0.3
  2. 로봇 연결을 확인하고 설치

    관리자가 확인한 버전과 기기 설정으로 도우미를 실행합니다. 도우미가 연결·환경을 검사하고 설치를 진행합니다.

    설치 명령과 단계 보기 ↗
  3. 설치 완료 화면 확인

    도우미가 만든 lekiwi-installed.html을 PC에서 열어 장치 이름과 Wi-Fi 연결 정보를 확인하세요.

이미 설치된 로봇을 업데이트하려면

처음 설치 도우미를 다시 실행하지 마세요. 설정과 기록을 백업한 뒤 수동 업데이트 안내를 따르세요.

03 / 로봇 연결

Wi-Fi 연결 후, QR을 스캔하세요.

  1. 스마트폰을 로봇 Wi-Fi에 연결

    설치 완료 화면에 표시된 Wi-Fi를 선택하고 암호를 입력하세요. “인터넷 없이 연결 유지”가 나오면 유지합니다.

  2. QR로 웹앱 열기

    이 QR은 웹앱 주소를 엽니다. Wi-Fi 연결이나 PIN 인증을 대신하지 않습니다.

  3. 기존 PIN으로 로그인

    조종·기록·시스템 관리 화면을 사용할 수 있습니다. 처음에는 주변 공간을 확보하고 낮은 속도에서 방향과 정지를 확인하세요.

로봇 웹앱

192.168.4.1:8090 ↗

로봇 Wi-Fi에 연결된 기기에서 열립니다.
QR이 안 되면 위 주소를 직접 입력하세요.

HELP

연결이 안 되나요?

로봇 웹앱이 열리지 않아요.

로봇 전원과 Wi-Fi 연결을 확인하세요. 인터넷이 없다는 안내가 떠도 연결을 유지하고 주소를 다시 열어보세요. 이 설치 안내 사이트는 로봇 조종 화면과 별개입니다.

설치 도중 오류가 났어요.

화면에 나온 오류를 확인하고 폴더를 지우거나 초기화하지 마세요. 문제 해결 안내를 따르거나 관리자에게 문의하세요.

조종 중 연결이 끊기면 마지막 이동이 최대 10초 유지될 수 있습니다. 즉시 정지가 필요하면 현장에서 모터 전원을 차단하세요.
