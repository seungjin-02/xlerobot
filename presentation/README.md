# LeKiwi · 혼자 둘러보는 소개 자료

`private/presentation-delivery/LeKiwi-introduction-v3.html` 하나만 전달하면 됩니다. 이미지와 시연 코드가 포함되어 있어 다른 파일이나 프로그램 설치가 필요하지 않습니다. 브라우저로 열고 **다음**을 누르거나 **자동 둘러보기**를 선택합니다.

현재 main의 조종·기록 기능에서 SLAM 센서 기록 확장으로 이어집니다. 버전별 2장, 전체 4화면으로, 첫 화면은 모바일 브라우저 → 로봇 AP → ROS 2 연결 구조와 조종·관측·기록·관리 기능을 실제 앱 이미지와 함께 소개합니다. 두 번째 화면은 기능별 캡처와 저장/관리 항목을 보여줍니다. 노트북·키보드에서 모바일 터치 운용으로 바뀌는 이점은 짧게 연결했습니다. 검증·한계와 향후 연구 장은 제외했습니다.

**설치 안내 ↗**는 기존 공개 사이트 https://seungjin-02.github.io/xlerobot/ 를 새 탭으로 엽니다. 소개 자료 자체는 오프라인으로 동작하며 외부 사이트에 접속할 때만 인터넷이 필요합니다.

## 다시 만들기

```bash
python3 presentation/build_delivery.py
```

관리형 브라우저가 로컬 HTML을 차단하는 경우 이 폴더에서 `python3 -m http.server 8088 --bind 127.0.0.1`을 실행하고 주소창에 `http://127.0.0.1:8088`을 입력합니다.

## 제작 기록
