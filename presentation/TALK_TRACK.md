# 5분 발표 대본

## 0:00–0:30 · main 1장 — 문제와 한 문장 소개

“로봇 실험에서는 움직이는 것만큼, 카메라를 켜고 상태를 확인하고 데이터를 정리하는 과정이 반복됩니다. 이 웹앱은 르키위의 조종·주행 기록·시스템 확인을 폰 브라우저에 모은 실험 도구입니다. 지금 보이는 3D 움직임은 구조를 설명하는 개념 시연이며 실제 로봇은 연결돼 있지 않습니다.”

강조: **로봇을 조종하는 화면에서 연구 데이터가 시작된다.**

## 0:30–1:15 · main 2장 — 실제 앱

조종 → 기록 → 관리 버튼을 눌러 실제 캡처를 보여줍니다. 필요하면 캡처를 확대합니다.

“첫 화면에서는 영상과 방향·속도를 보고 조종합니다. 기록 화면에서는 작업 설명과 주행 결과를 남깁니다. 시스템 화면에서는 버전과 연결·저장 공간을 확인합니다. 준비된 장치에서는 로봇의 로컬 Wi-Fi로 사용하므로 운용 중 클라우드가 필수는 아닙니다. 최초 설치와 ROS 설정은 별도로 필요합니다.”

## 1:15–1:45 · main 3장 — 데이터가 남는 흐름

“직접 수행한 주행을 하나의 에피소드로 남깁니다. 영상뿐 아니라 로봇의 위치·속도와 제한이 적용된 명령을 저장하고, 성공·실패를 표시해 ZIP으로 가져갑니다. 기존 변환 도구로 이미지·상태·행동의 학습 형식을 준비할 수 있지만, 앱 안에서 자동으로 학습시키는 기능은 아닙니다.”

## 1:45–2:15 · main 4장 — 차별점

“차별점은 새로운 SLAM 알고리즘보다 실험 절차의 통합입니다. 터미널, 영상 도구, 파일 정리로 나뉘어 있던 작업을 같은 웹앱에서 연결합니다. 비전문가가 반복 시범을 수집하거나 연구자가 기록을 일관되게 관리하기 쉽게 하는 방향입니다. 다른 모든 제품보다 빠르다는 성능 비교를 한 것은 아닙니다.”

## 2:15–2:40 · latest 1장 — 확장의 핵심

상단 **02 SLAM 확장** → 1장.

“두 번째 버전은 아직 main에 병합하지 않은 확장입니다. 기존 주행에 공간 센서 원본을 함께 남겨서, 사람이 조종한 경험을 지도 생성의 재료로 쓰도록 연결했습니다.”

## 2:40–3:10 · latest 2장 — 한 옵션의 의미

“화면에는 ‘SLAM 지도용 센서도 기록’ 옵션이 추가됩니다. 체크하고 기록을 시작하면 LiDAR·이동량·좌표 관계와 실제 제공되는 IMU 등의 데이터를 bag으로 저장합니다. 필수 입력이 없거나 잘못 연결되면 오류를 표시합니다. 지금 데모에서는 실제 센서가 없으므로 비활성 상태입니다.”

## 3:10–3:45 · latest 3장 — 지도에서 주행까지

진행 막대를 이동해 단계를 보여줍니다.

“현장에서 수동 주행하며 기록하고, Ubuntu PC의 별도 도구로 SLAM Toolbox 지도를 만듭니다. 지도 확인 후 AMCL로 위치를 추정하고 Nav2로 경로를 따라가도록 연결했습니다. 명령과 센서가 끊기면 정지·비활성화를 요청하는 중계기를 둡니다. 지도 생성과 목표 지정은 아직 웹 기능이 아니며 자율주행 실행은 별도 도구입니다.”

## 3:45–4:25 · latest 6장 — 검증과 한계

“Python 154개와 브라우저 20개 검사를 통과했습니다. 합성 방의 센서 데이터를 실제 ROS·SLAM Toolbox·Nav2에 넣어 기록, 지도·pose graph 저장, 가상 모터의 목표 도착까지 확인했습니다. 이 지도는 실제 공간이 아니고, 이 결과가 실물 주행 안전성을 증명하지도 않습니다. 실제 센서 드라이버, 장착 좌표, 이동량, 로봇 크기와 정지 성능은 기기 연결 후 검증해야 합니다.”

## 4:25–5:00 · latest 7장 — 연구 방향

“다음은 실제 공간에서 보정과 지도 품질·반복 주행을 평가하는 단계입니다. 이후에는 지도와 목표 지정 UI, 센서 시간 정렬, 학습 데이터 변환과 정책 비교로 확장할 수 있습니다. 현재의 가치는 조종으로 끝나던 실험을 재사용 가능한 데이터와 지도 제작 흐름으로 이어 준다는 데 있습니다.”

## 질문에 짧게 답하기

- **이미 자율주행하나요?** Nav2 연결 도구를 구현하고 합성 입력으로 확인했습니다. 실제 로봇 주행은 아직입니다.
- **학습해야 지도가 생기나요?** 아닙니다. 이번 2D 지도는 SLAM으로 만들며 정책 학습과 별개입니다.
- **체크하면 바로 지도가 보이나요?** 아니요. 센서를 기록하고 별도 PC 도구로 지도를 생성합니다.
- **새 알고리즘인가요?** 기존 ROS·SLAM Toolbox·Nav2를 기록/운용 흐름에 통합한 앱입니다.
- **어떤 연구가 가능한가요?** 시범 수집·재현과 현장 지도/주행 평가가 출발점입니다. 다중 센서 정책 학습에는 추가 export·trainer·평가 설계가 필요합니다.
