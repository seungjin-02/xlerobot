# 합성 센서 검증 자료

이 폴더의 지도는 6m×6m 가상 방입니다. 실제 장소 지도나 실물 주행 검증이 아닙니다. 실제 ROS Jazzy SLAM Toolbox/Nav2에 합성 scan/odom/TF와 가상 모터를 연결해 검증했습니다.

`verification.json`은 검사 결과, `synthetic-mapping-report.json`과 `synthetic-navigation-report.json`은 실제 실행 출력을 담습니다. 원본 bag과 전체 로그는 Git에 넣지 않고 `private/slam-verified`에 보관합니다.
