# 공개 설치 포털과 배포 출처

## 현재 출처

`https://github.com/seungjin-02/xlerobot.git` 원본은 2026-10-15 사용자가 직접 Public으로 전환했습니다. PC에서 인증 없는 Git fetch와 태그 조회를 확인했습니다. 검증된 운영 릴리스 태그는 아직 없습니다. [개발 지시서별 상태](REQUIREMENTS.md)를 참고하세요.

원본 공개와 별도 공개 배포 저장소를 비교한 결과는 CONTROL_CENTER.md에 남아 있습니다. 이번에는 사용자가 선택한 원본 공개 방식을 따릅니다. 도우미의 출처 상수를 바꾸거나 다른 Git 저장소로 배포하지 않습니다.

프로젝트 앱/문서에 대한 새 공개 사용·재배포 라이선스를 부여하지 않습니다. LICENSE-NOTICE.md와 드라이버 Apache-2.0 고지를 확인하세요.

## 설치 안내 사이트

원본은 `site/`의 buildless HTML/CSS입니다. 조종 API·장비 인증 정보·기록 데이터를 포함하지 않습니다. 설치 포털과 로봇의 `http://192.168.4.1:8090` 로컬 앱은 별개입니다.

공개 설치 포털: https://lekiwi-control-center-install.psj22037540.chatgpt.site

호스팅은 Sites이며 GitHub의 `site/` 파일을 정적 배포합니다. GitHub Pages는 아직 활성화하지 않았습니다. Pages로 이전하려면 저장소 Settings → Pages에서 GitHub Actions를 선택하고 `.github/workflows/pages.yml`을 수동 실행합니다. 다른 호스팅으로 옮겨도 로봇 앱·PC 도우미·Git 배포 출처는 변경할 필요가 없습니다.

포털 변경은 GitHub feature→테스트→PR→main 절차로 검토한 뒤 `site/` 파일과 같은 상태를 다시 게시합니다. 호스팅 설정·배포 자격 증명·개별 로봇 설정은 GitHub 앱 소스에 넣지 않습니다.

## 공개 전후 점검과 한계

현재 Git 전체 이력은 4개 커밋입니다. 도달 가능한 blob 및 보관 ZIP 내부를 포함해 토큰·개인키·인증 URL 패턴과 설정/PIN/AP 관련 필드를 검사하고 외부 드라이버 출처·라이선스 고지를 검토했습니다. 테스트용 값과 설치 기본값은 실제 개별 기기의 비밀 백업과 구분합니다. 패턴 검사 통과를 비밀 누락이 절대 없다는 보장이나 포괄적 법률 감사로 표현하지 않습니다.

공개 이력에 기기 이름·사설 IP·USB 포트 경로와 과거 검증 증거가 있습니다. SSH 자격 증명·실제 설정 파일·실물 기록 백업은 이번 변경에 포함하지 않습니다. 실제 기기의 PIN/AP 암호가 문서의 기본값이나 테스트 예시와 같다면 관리자가 별도로 변경해야 합니다. 자동 업데이트 도우미가 이를 임의로 변경하지는 않습니다.

## 운영 릴리스로 승격하기 전

1. 배포할 정확한 커밋에서 Python/Chromium/CI를 통과합니다.
2. 깨끗한 Ubuntu 24.04 ARM64에서 Git clone→태그/SHA→의존성→colcon→서비스→재부팅/AP/QR/PIN·카메라를 실제 검증합니다.
3. 모터 활성화 전 현장에 알리고 방향·저속 주행·정지·통신 단절/복구를 검증합니다.
4. 기록/다운로드/LeRobot 변환과 기존 설치 업데이트·설정/기록 보존·복구 시험을 완료합니다.
5. 지원 환경·시험일·실패/미실시 항목·커밋을 남긴 후 실제 운영 태그를 생성합니다. 태그가 있다는 이유만으로 검증 완료로 보지 않습니다.

새 태그·GitHub Release와 자동 업데이트 실행 기능은 이번 보완에서 생성하지 않습니다.
