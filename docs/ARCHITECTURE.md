# 작동 구조와 동작 계약

폰 브라우저 → 로봇 AP(192.168.4.1) → Python HTTP 서버8090 → Controller → RosBackend → ROS_DOMAIN_ID42, localhost discovery → lekiwi_node → Feetech 모터.

카메라 Python 서버8080은 USB 카메라를 MJPEG로 전송합니다. UI는 선택한 index를 표시하며 기록 스레드는 index0 본체 JPEG를 받습니다. 설치 서비스는 lekiwi-phone.service / lekiwi-camera.service이고 사용자 Linger로 부팅 시 시작합니다. 앱 부팅은 모터 활성화를 의미하지 않습니다. 조종 시작 후 바퀴 노드 준비와 모터 활성화 절차를 수행합니다.

방향 버튼은 토글이며 같은 버튼은 정지, 다른 버튼은 멈춤을 끼우지 않고 slew 제한으로 전환합니다. 한 폰만 조종 권한을 갖습니다. 연결 손실 시 마지막 출력을 최대10초 유지하며 .6초 이상 명령이 없으면 추가 가속하지 않습니다. 10초 경과 시 정지/토크해제, 출력 자체가 멈추면 드라이버의 .3초 timeout이 적용됩니다. 폰의 정지 클릭은 통신 단절 중 전달되지 않습니다.

속도 1배=.03m/s, 기본10배=.30, 최고30배=.90 요청; 회전 요청은 이동 숫자5배(rad/s): .15~4.5, 기본1.5. UI 요청과 실제 물리 속도는 다릅니다. 바퀴 포화·모터 ticks 상한을 비례 적용하고 실제 발행 Twist를 기록합니다. 원본 요청과 상태 속도도 별도 보존합니다.

기록은 제어 루프와 분리한 큐(최대256개)로 디스크에 씁니다. 목표20Hz; 센서 신선도와 연결 상태로 training_valid를 표시합니다. 저장 공간256MB 미만이면 시작 거부, 기록 중128MB 미만이면 중단합니다. 기록 종료 버튼은 주행도 정지하고 .3초 terminal 관측을 저장합니다.

웹 UI는 HTTP 로봇 로컬 주소에서 제공합니다. 오프라인 앱/PWA/APK는 현재 구현하지 않았으며 보류 중입니다. 로봇 Wi-Fi에서 벗어나면 웹 화면 최초 로드가 되지 않는 현재 제약을 유지합니다.
