# 웹 조작기 전환

XLeRobot 트롤리의 기존 웹 오퍼레이터와 새 웹앱을 하나씩 실행한다.
전환 화면은 어느 모드에서나 `http://로봇주소:8091/`이며 새 웹앱과 같은
접속 코드로 로그인한다. 새 웹앱의 시스템 관리에도 전환 링크가 있다.

- 내 웹앱: 8090. 카메라는 8080, LiDAR 사용자 서비스를 함께 실행한다.
- 기존 웹 조작기: 8080. 새 웹앱·카메라·LiDAR 사용자 서비스를 종료한 뒤 실행한다.
- 주행·기록·팔 세션·보정·PC 조종이 진행 중이면 전환하지 않는다.
  기존 화면에서는 지도 저장 후 로봇/지도 작성/자율주행 기능을 종료한다.
- 전환은 모터를 켜거나 목표를 보내지 않는다. 이전 세션도 복원하지 않는다.
- 이전 서비스 종료와 직렬 장치 해제를 확인한 후 대상 서비스를 시작한다.
  시작 후 대기 상태 확인에 실패하면 대상 서비스를 종료하고 이전 모드로 복귀한다.
- 마지막 성공 선택만 root 소유 상태 파일에 기록한다. 부팅 서비스가 이를 읽는다.
- systemd 시작 전 검사로 반대쪽 조작기가 실행 중인 경우 수동 서비스 시작도 거부한다.

웹 서버는 roboseasy 사용자로 실행하며 root 명령은 고정된 전환 helper만 호출한다.
PIN 세션, 동일 Origin 검사, 제한된 요청 크기와 로그인 시도 제한을 적용한다.
helper와 정책은 root 소유 경로에 설치한다. 운영 파일·지도·기록·네트워크 설정은
전환 시 삭제하거나 수정하지 않는다.

하드웨어 연결 상태와 기존 조작기의 상태 형식은 기기마다 다시 확인해야 한다.
이 구성의 실물 검증은 서비스 전환과 정지 상태에 한정하며 주행 검증을 뜻하지 않는다.
